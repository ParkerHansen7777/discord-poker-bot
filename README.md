# Discord Poker Bot

A Discord bot that provides a Texas Hold'em poker experience for friends directly within a Discord server. The goal is to create an alternative to Discord's Poker Night Activity, with persistent player balances, a chip banking system, loans, and competitive leaderboards.

## Features

### Poker Gameplay
- Texas Hold'em poker gameplay.
- Interactive poker tables with player cards, chip stacks, and community cards.
- Player actions including fold, check, call, and raise.
- Multiplayer games within a Discord server.

### Chip Banking
- Persistent chip balances for each player.
- Deposit and withdraw chips from the bank.
- Allow players to take out loans when they run out of chips.
- Track outstanding loans and repayments.

### Leaderboard
- Server leaderboard ranking players by chip balance.
- View player standings and compete with friends.
